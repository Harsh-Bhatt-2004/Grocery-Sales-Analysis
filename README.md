# SnapGrocer Grocery Sales Analysis (Power BI)

## Overview
This Power BI project provides an analysis of grocery sales data for SnapGrocer, aiming to identify trends, patterns and insights to support business decisions.

## Data Souce
Here we use the data of SnapGrocer for deep analysis where we have the data about outlets, locations, size based on outlet type, fat content, item categories and other. Our aim to produce a dashboard with different analytical and interactive charts. 

## What to do
We analyze grocery sales data to uncover:
 - Sales trends over a time
 - Customer segmentation
 - Geographically distributed sales
 - Top-performing products and categories

## Objectives
 - Discovering the top and valuable products to manage the inventory for such outlets
 - To identify the years and respective number of outlets are established
 - Customer grouping to manage marketing efforts
 - Visualization sales data across different locations and what kind of outlet type is preferred by the customer most.

## DAX and Filters Applied
 ### DAX Measures:
  - **Total Sales**: Calculated using the **sum** function to aggregate sales data.
  - **No. of Items**: Measured using **count** of items to be sold by the outlets.
  - **Average Rating**: Based on outlet type what should be the **average** rating.
  - **Average Sales**: Just calculate the **average** sales on different outlet locations.  
 
 ### Filters:
  - **Fat Content Filter**: According to the selection of **fat content**, we can filter out the data on all visuals created in our dashboard.
  - **Outlet Location Type**: From available locations, we can select and check the sales, ratings, fat content, etc.
  - **Item Type**: Based on different items, we can see what items are frequently liked and purchased by customers over a year. 
  - **Outlet Size**: There are different sizes of outlets (small, medium, and large), and according to the selection, we can see the sales and ratings given by customers based on items' availability and price. 

## Visualization Examples
 - **KPIs**: We created four KPI Cards to describe total sales, average sales, number of items, and the average rating given by outlets over a year.
 - **Fat Content and Outlet Size**: We used a donut chart to visualize the distribution of data based on fat content and outlet size.
 - **Outlet Establishment**: We used a line chart to display the number of outlets established over the years, highlighting a peak in 2018 when the maximum number of outlets were established.
 - **Outlet Type**: We created a tabular info chart where data is displayed according to the outlet type, providing detailed KPI information.
